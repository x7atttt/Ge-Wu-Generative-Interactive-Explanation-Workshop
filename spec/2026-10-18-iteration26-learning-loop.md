# 学习闭环打磨：可信状态、今日任务、自测恢复与资料纠错

> 状态：done
> 创建：2026-10-18
> 授权：用户要求按建议迭代，并提供自行验收方法。

## 目标与用户故事

1. 学习者刚开始作答时看到“待巩固”；练习达标与自评记忆分开展示，忘记的卡能提示回顾。
2. 进入空间后直接开始今日到期复习、补弱或路线下一概念；新空间可直达资料入口。
3. 自测中途关闭或刷新后继续；完整报告可回看，并可复习本次忘记的卡、查看相关讲解。
4. 导入后查看/搜索正文、修正内容、编辑概念；改动提示路线更新，历史讲解依据保持快照。
5. 难卡可暂时移出本轮并查看讲解，到期状态保留；结束页准确报告暂缓项。
6. 地图/路线/资料操作失败后保留已有内容，原位显示错误并可重试。

## 决策与边界

- 不新增依赖、不升级技术栈、不引入模型调用用于任务推荐；真实资料与空间不用于变更测试。
- `learning` 表示已有作答但证据不足；沿用当前最少样本与正确率阈值，以“练习达标”替换“已练成”，不声称掌握。自评分独立展示。
- 新增复习日志，记录卡片最近评分；旧评分不猜测补造。自测逐题更新排期，答案写入与排期同一事务，重复提交幂等。
- 自测保存题目快照与逐题答案；空间删除同时清理会话，删卡后历史报告仍可看，作答中的已删卡明确提示处理。
- 资料修正使用版本号检查并发；正文变更清空提炼缓存。新讲解存生成时实际使用的资料快照，深化继承父版本。旧讲解未存依据时明确“未记录”，不伪造。
- 路线过期时提示更新，不静默删除旧路线或自动触发模型。第一版资料纠错为纯文本编辑，避免解析 HTML 执行风险。
- “稍后再练”仅移出当前复习队列，不写评分、不改排期。复习展示原始卡片数、评分次数与暂缓数。

## 验证方案（完成后逐项填实测）

- [x] 单次答错不会被路线计为达标；足量正确练习可达标；自评忘记单独提示，复习后消除。
- [x] 今日任务按到期/回顾/路线推进；完成后刷新；无资料直达导入、无概念直达提炼。
- [x] 自测重复评分不重复排期；中途退出/刷新可恢复；报告可回看且补弱仅包含本次忘记卡。
- [x] 资料预览搜索、正文/概念保存、旧版本冲突、非就绪/非法输入；地图更新、路线过期提示。
- [x] 资料修正不改变已有讲解的快照；深化继承快照；旧讲解明确未记录。
- [x] 难卡暂缓后仍到期，结束页数字准确，原讲解入口与报告相关讲解共用打开回调。
- [x] 模拟地图/路线/资料失败，旧内容保留，重试成功恢复。
- [x] 构建与类型检查通过；执行 Lint 并对照基线（遗留问题见下）；一次性空间接口与桌面/窄屏验证通过。
