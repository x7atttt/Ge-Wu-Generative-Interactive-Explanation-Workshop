# 讲解生成与持续深化的一致性

> 状态：implemented

## 目标

一篇讲解持续完善，生成中已就绪的图保持可见；即时深化与历史恢复显示相同内容，原始讲解可找回。

## 产品取舍

- 历史以原始讲解归组，默认打开最新版本；展开版本记录查看原始讲解与任意保存版本。删除针对整篇讲解及全部版本，沿用明确确认。
- 深化默认“补充讲解”，保留原有标题和全部块，仅追加内容；显式选择“修订原文”才允许修改既有内容。服务端检查该约束，共享原有一次修复预算，失败不保存。
- 补充标记只用于完整保留前版的追加部分。修订/旧历史中的重写不再用首个不同位置把原文包进补充框；显示版本性质及原版入口。
- 沿用现有版本链与存储，不改写或删除用户旧数据。历史归组通过可选查询提供，原始列表接口保持兼容。
- 图表等待真实节点和视口就绪后定位；相同已完成块不随后续流片段反复初始化。修复以分段慢速流测试证明，不能只在生成完成后验收。

## 验收

- [x] 慢速流中图完成后持续可见，节点在图框内，后续正文更新和成品切换不出现空白。
- [x] 默认补充保护原文；非法改写修复一次或停止保存；显式修订可修改。
- [x] 多轮追加分组准确；先修订再补充、旧历史改写不误标原文。
- [x] 历史一篇一入口、默认最新、版本切换与搜索、整篇删除；刷新后显示一致，旧数据自动归组。
- [x] 生产构建、定向检查、接口与桌面回归，截图实际查看，恢复开发服务。
