# 从临时生成结果到持续完善的讲解

用户反馈：流式生成中的图会空白；深化像是替换原文；历史把原版和深化版并列，而打开后又混在一起。要求从产品角度优化。

产品决策：一篇讲解一个历史入口，默认打开最新版本，保留原始讲解与所有版本；默认追加补充，显式修订才改原文。沿用已有 parent 链，不清理或改写旧数据。

实施与验证修整：

- 首个不同块只能表示出现了变化，不能证明其后全是补充。分段改为检查完整前版前缀，遇到修订清除失效边界；对象字段顺序不参与内容判断，避免输入校验重排字段造成假变化。
- 新界面明确发送 append/revise，旧客户端未传 mode 保持原语义。append 在保存前检查标题与原文完整性，违规使用原有一次修复机会，再失败不保存；不单靠提示词约束模型。
- 历史提供可选 grouped 查询，保持旧扁平列表兼容；以根版本删除整篇，点击主入口打开最新，版本记录打开准确快照。跨空间打开时同步归属空间。
- 图采用稳定的受控节点/连线与已完成块，布局尺寸显式传入节点；从实际节点/端口测量与视口就绪状态触发定位。检查已安装渲染库发现，重复传入新节点会清空测量信息，不能依赖后续正文或生成结束促成初始化。
- 增加分段慢速模型替身与 ReAct 跨组回路图，验证生成尚未结束时图已就绪、节点在图框内、后续流片段保持同一图实例。截图检查曾发现初始化遮罩仍在，补充就绪断言，修正后再实际查看。

验收使用本地模型替身与一次性空间，不额外调用真实模型。生产构建、定向 ESLint/存量问题对比、持续深化接口与桌面回归、既有布局/复核/传输/教学回归结果记录于同日 spec。
