# diagram 与 effort 迭代引导

用户：做 diagram 块，不做 image 块；现有模型支持 effort low/high/max 切换；完成后自校验视觉效果。

实现约束：沿用现有受限 DSL 与生成校验修复管线。模型输出结构语义，程序负责布局；保持纸墨朱砂风格。effort 原值请求，不替换 max，不放宽校验。

实现：

- 增加 diagram 结构契约与引用校验，接入现有生成、流式解析、一次自动修复、存储恢复和深化管线。架构类主题优先输出 diagram，量化实验继续使用 chart/wavePlot。
- React Flow 只负责只读图与视图交互，ELK 负责布局；不让模型生成坐标或执行代码。
- 工具栏增加思考强度，默认 high，本机保存；low/high/max 原值覆盖生成、深化、追问及修复请求。旧客户端省略参数时保留服务端配置兼容。

验证驱动的修整：

- 首轮复合图发现组内边使用局部坐标，必须转换到画布坐标；完整缩放后图形过长、字太小。调整为先排组内、再排组间，边界连线接回实际模块，并校验所有连线端点。
- 浏览器发现只读节点被画布拦截点击，显式保留模块按钮的指针事件；修整分组标题、边标签层级。
- 实际查看桌面与窄屏截图后，窄屏默认聚焦第一步；单组聚焦包含分组边界，避免标题裁切，保留总览与模块导航。
- 测试增加流式预览和最终文档分别排布的同步等待；已有悬停菜单测试补充渲染等待及明确的低视口定位，避免依赖旧工具栏高度。

验收使用本地模型桩与可清理数据，覆盖请求参数、合法/非法 diagram、历史恢复、深化、追问、键盘和移动宽度；不推断真实供应商的生成质量。
