# 悬停下拉 · 开发协作记录

> 本文件为事实摘要，并非完整对话导出。

用户标注空间和讲解风格两个原生 select，反馈视觉简陋，要求悬停直接显示下拉。

实现选择：

- 共用 HoverSelect：纸色面板、独立选项行、辅助说明与选中标记；空间沿用青色，风格沿用暖色。
- 鼠标进入即开，菜单与触发器之间留出可进入的区域，并设置短暂离开缓冲；点击、触屏与键盘继续可用。
- 悬停不改变焦点或选择；显式选择后提交原值。两个下拉互斥，外部点击、焦点离开、Escape 和 Tab 关闭。
- Portal 浮层根据视口和触发器位置确定左右位置、向上/向下与可用高度；选项内部滚动，长名称换行。
- 空间新建输入换行以适应窄屏；保留空间切换/彻底删除、风格自定义与持久化逻辑。为风格增加简短显示说明，原注入模型的 hint 不改。

验证过程：共享组件先通过类型与专项 Lint；原有浏览器脚本改为点击自定义选项。新增专项验证悬停连续、互斥、不抢焦点、关闭方式、方向键与首字母定位、刷新恢复、自定义/预设风格的实际生成请求、窄屏新建/删除和触屏。首次截图中风格说明较长，随后压缩显示文案并调整可用高度，补充常规窗口中自定义选项可见检查。
