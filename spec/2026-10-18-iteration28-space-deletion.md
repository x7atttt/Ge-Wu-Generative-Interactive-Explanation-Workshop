# 空间彻底删除与界面同步

> 状态：done

## 用户反馈与验收目标

删除空间后仍显示旧条目、当前选择和“空间不存在，已保留上次内容”。用户要求删除后直接彻底删除。

- 两个删除入口均在一次明确确认后删除空间及其资料、讲解、练习记录、卡片、复习日志与自测记录，移除仅删容器的选项。
- 删除事务成功后立即从选择器和管理面板移除，删除当前空间则返回全局；清除对应讲解、历史、附加资料及缓存面板。
- 不依赖再次请求列表才能反映已确认的删除；较早发出的列表/讲解请求不能在删除后恢复旧内容。
- 地图遇到真实的空间不存在响应，退出失效空间；普通网络/服务错误仍保留内容并支持重试。
- 删除失败保留原内容，提供错误；取消/Escape/遮罩仍无删除请求。只用一次性空间做删除测试，不补删无法追溯归属的旧内容。

## 定位与方案

管理面板删除仅触发异步列表刷新，未通知父页面移除和退出；刷新失败被吞掉。增加明确的删除结果回调，父页面统一清理，并用请求序号隔离旧响应。后端把删除改为统一深删并使用事务，返回被删讲解和资料编号。404 与普通失败分别处理。

## 验收清单

- [x] 工具条及管理面板当前/非当前空间删除；一次确认；取消不删除；失败可重试。
- [x] 列表刷新失败、旧响应延迟返回、讲解请求迟到均不会恢复已删内容。
- [x] 失效持久化选择与地图 404 退出；地图 503 继续原位重试。
- [x] 数据完整级联、重复删除幂等、失败事务回滚；其他空间内容不变。
- [x] 构建、接口/浏览器专项与既有回归；恢复开发服务并更新验收记录。
