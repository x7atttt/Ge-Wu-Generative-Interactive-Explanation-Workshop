# 修复确认流程、讲解排版与复习卡完整性

> 状态：done
> 创建：2026-10-18

## 用户问题与验收目标

1. 空间删除取消后立刻结束；保留资料与连同内容删除是明确选择，采用与页面一致的确认弹层。
2. 正文/练习/卡片正确展示 Markdown；填空代码保留换行和缩进，兼容历史换行标签。
3. 选择题卡片保留选项，填空保留完整上下文、空号和候选项；残缺题干不能作为有效自测。
4. 学习状态说明准确，图例与概念卡片共用颜色；已生成但未作答与已作答样本不足分开展示。
5. 图表绑定范围可见；生成时拒绝未说明的局部单点参数绑定。截图中的递归图修为同一 n 下两个阶段同步变化，修正残缺题干。

## 决策

- 沿用既有 Markdown 依赖，不执行原始 HTML，不引入任意表达式执行器。代码题增加可选语言标记，历史真实换行或 br 标签按原意显示，不猜测单行代码的缩进。
- 生成质量门与存储校验分开，避免严格新规则导致旧讲解不能读取；把残缺题干、代码题无换行、未说明的稀疏参数联动反馈给现有自修复链。
- 卡片转换为可独立作答的题面。仅对能按来源题面及答案精确匹配的旧自动卡补全内容，保留卡片编号和排期、人工编辑；已完成自测保持历史快照，进行中自测兼容补全。
- 残缺题卡明确提示不可评分并可跳过，不因此修改记忆状态。
- 删除确认与放弃草稿统一弹层，Escape/遮罩/取消均只取消本次动作。
- 只修正用户所指的错误学习内容，修正前备份对应记录，不批量重写其他学习资料。用户已删除的 handoff.md 保持删除。

- [x] 删除取消/Escape/遮罩不发删除请求；两种删除模式明确且各只发一次请求；错误显示可重试。
- [x] 正文加粗、行内码、代码块安全渲染；代码填空保留缩进，题目选项和答案完整。

- [x] 新生成质量门拒绝残缺题干、单行复合代码、未说明的稀疏绑定；有明确说明的单点互动可用。
