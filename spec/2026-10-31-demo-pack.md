# 演示数据包

目标：新环境执行一条命令即可查看预置资料、概念地图、交互讲解及版本历史，不依赖模型请求。

- 使用独立演示空间，明确预置来源；不导入个人追问、成绩或复习记录。
- JSON 包可入库；本地脚本校验 DSL 和全部关联，再在事务内导入，重新分配 ID。
- 同包重复导入不重复插入；同标识内容变化拒绝覆盖，已删除空间允许重新导入。
- 写入已有库前用 SQLite 在线备份；导出指定空间，拒绝覆盖输出文件。
- 随仓库提供精选案例及 README 路径，不增加网页管理模块或公开 API。

验收：空库导入、重复导入、关联与版本恢复、导出再导入、非法输入无写入、已有数据保留、生产构建与定向 Lint。

状态：已完成。

- 提供 `scripts/demo-pack.mjs` 与 `demo/showcase.json`；内部 `demo_imports` 表仅用于包标识、内容摘要和空间关联，不改变业务表或公开 API。编辑空间说明不影响重复导入判断。
- 精选包：波形原文与追加补充、算法流程讲解，合计 3 个版本；2 份资料、3 个概念及学习路线。所有预置来源均标明，不模拟个人成绩。
- `node test/demo-pack.mjs`：空库、幂等、内容变更拒绝、资料/版本关联、导出回读、非法输入、事务回滚、已有空间保留及 SQLite 备份验证通过。
- `pnpm build`、脚本定向 ESLint 通过。`python test/demo-pack-ui.py` 在本地隔离验收端口通过；桌面截图人工检查波形、流程图和补充卡片可读。
- 已为当前库生成写入前备份并导入独立演示空间，重复导入确认跳过；没有修改原有讲解或制造作答记录。
- 没有调用真实模型，不把这些结果当作生成速度或内容复核效果验收。
