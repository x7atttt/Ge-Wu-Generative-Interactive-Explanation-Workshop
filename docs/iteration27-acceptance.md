开发服务恢复后刷新页面。沿用现有环境与依赖，本轮没有新增数据库表或付费服务。

## 删除确认

在专门的测试空间检查，避免删除自己的学习资料：

1. 点空间旁的删除按钮，应看到不可恢复的范围和红色“彻底删除空间”按钮。
2. 后续修复已统一为删除空间及其内容，不再提供仅删空间的选项；详见 `iteration28-acceptance.md`。
3. 分别点击取消、按 Escape、点击遮罩：弹层关闭，不再出现第二次确认，空间与内容保留。
4. 新建两个测试空间并各放一份讲解，分别从工具条和空间管理面板删除。空间及其中内容应一并移除，当前地图退出，列表立即消失。
5. 历史讲解、卡片删除和放弃资料草稿使用同样的弹层。草稿取消放弃后仍在原处。

## 讲解和代码排版

1. 打开“递与归两个阶段”。正文应展示加粗、列表和代码块，不再把 Markdown 加粗符号当作正文。
2. 代码填空应按函数、分支、返回语句分行并保留缩进。空位有独立编号，选项在题目后列出。
3. 历史讲解中的 br 换行标签按换行显示；代码围栏里的字面标签保留，不执行 HTML。
4. 在窄屏中，长代码可在代码区域横向滚动，页面整体不应横向溢出。

## 卡片与自测

1. 从有选择题和代码填空的讲解制卡，进入复习或自测。选择题应包含完整问题与全部选项，代码题包含上下文、空号与候选项。
2. 重复制卡不新增相同题目；不完整的题目单独报告“未制卡”，与重复跳过区分。
3. 能精确匹配来源题面和答案的旧自动卡会补全，保留编号及排期；人工修改不被覆盖。
4. 进行中自测恢复后仍可显示补全后的题面。已完成报告保留当时的快照。
5. 历史残缺题提示不可评分：自测可“跳过不完整题目”，复习可暂缓并编辑。跳过不更新记忆状态，全部跳过时报告显示“未计分”。
