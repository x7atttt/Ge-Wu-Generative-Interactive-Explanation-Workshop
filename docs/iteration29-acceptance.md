# 悬停下拉面板 · 自行验收

刷新页面后，检查顶部“空间”和“讲解风格”两个入口。

1. 鼠标移到入口，不点击就应展开自定义面板。移入选项后应保持展开；移出后关闭。切到另一个入口时，前一个收起。
2. 在概念输入框输入文字并保持焦点，再悬停入口，输入焦点与文字应保留。点选选项才会更改当前值。
3. 空间面板显示资料/讲解数量，长名称可以换行查看，当前空间带勾选。选择其他空间后地图和历史按原逻辑切换。
4. 风格面板显示简短说明，选择“自定义”后可输入人设；刷新后恢复所选风格和自定义文字。
5. 用 Tab 聚焦入口，方向键展开和移动，Home/End 到首尾，Enter/空格确认，Escape 收起；Tab 离开面板且不改变选择。
6. 点击页面其他位置应关闭面板。触屏用点击展开、点击选项选择，不要求悬停。
7. 在窄屏与较矮窗口检查：浮层保持在视口内，必要时向上展开；长列表内部滚动。选“新建空间”，输入框换行后仍在页面内，新建和彻底删除功能正常。

自动验证：停止开发服务后运行 `pnpm build`，再运行 `python test/run-learning-loop.py`。只验证新下拉可运行 `python test/run-learning-loop.py --hover-only`。测试创建一次性空间，使用本地模型替身验证风格参数，结束后清理测试数据和服务。
