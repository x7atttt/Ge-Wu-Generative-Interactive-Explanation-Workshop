# 空间彻底删除 · 自行验收

刷新页面后，新建专门的测试空间与资料进行删除验证。

1. 从工具条删除当前空间，确认窗应明确列出不可恢复的内容范围，只有“取消”和“彻底删除空间”。取消、Escape、点击遮罩都不删除。
2. 确认后应立即回到全局，当前地图与讲解清空，下拉框里不再有该空间。历史讲解和资料列表也不应残留相应内容。
3. 从空间管理面板删除当前空间，行为相同；删除其他空间时，保留当前选择和当前讲解，只移除被删除的条目及内容。
4. 刷新页面后已删空间不再出现。曾保存了失效空间选择时，收到明确的“不存在”响应应退出；普通服务失败仍显示重试入口。
5. 删除失败时空间和内容保留，可以重试；删除进行中禁止重复提交。

自动验证：停止开发服务后运行 `pnpm build`，再运行 `python test/run-learning-loop.py`。仅跑删除专项可用 `python test/run-learning-loop.py --deletion-only`。

删除专项使用一次性空间，验证资料、讲解及深化版本、追问、练习、自动卡/手写卡、复习日志、自测记录和答案的完整删除，并用数据库触发器模拟中途失败，确认事务回滚。浏览器主动扣留旧列表、旧讲解响应，确认删除后不会复现旧内容；另验证列表失败、失效选择、当前/非当前入口及其他空间不受影响。

删除行为在本轮改为统一彻底删除。此前通过旧“仅删除空间”功能移到全局、且已失去空间归属的内容，不按名称推断归属追删。
