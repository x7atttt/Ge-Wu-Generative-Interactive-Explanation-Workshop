# 架构图布线与生成精简验收

## 实现

沿用现有 ELK 与 React Flow：完整层级图统一布线，每条边独立输入/输出端口，固定端口顺序并关闭合并。节点、分组标题和边标签按字体测量并换行，直接使用引擎路径和标签位置。横纵候选依次比较遮挡、重合、可读缩放、留白与折弯；图内支持自动、横向、纵向，原 direction 仅作自动平手偏好。画布高度在 420–900px 内适配。

几何缓存共享在途 Promise，最多 16 组，失败删除。说明、步骤、预览转成品不改变几何键；宽度变化只重选方向和缩放。分步切换保持节点坐标。方向切换须等待实际画布高度更新后适配，避免沿用旧高度裁切内容。

正文、改造、追问和修复保持原有 effort 规则；保存前复核固定主模型 low，整阶段预算 90 秒，覆盖重试退避。完整检查、一次共享修复预算、取消和失败不保存保留。复核传完整新文档及用户资料/图片；改造复核不再重复附上整份旧文档，改造和修复仍保留它。普通讲解以核心案例、主要图示和一道迁移题为主；架构图通常 5–10 节点、2–4 步，均为软目标；补练至少五个练习块的要求未变。

不改 DSL、HTTP 字段、数据库或依赖；不缓存整篇模型讲解。阶段耗时、实际档位、请求次数和失败原因仍由现有日志记录。

## 隔离回归

`pnpm build` 与 TypeScript 通过。`python test/run-learning-loop.py --diagram-speed` 通过，包含：

- 分组、跨组、平行边、残差、回路、自环、长标签和无边节点的几何与端点检查；缓存共享、描述变化复用、失败重试与容量淘汰。
- 重建分叉汇合图：自动纵向、上方分区主线、左右递归并排、下方独立端口汇合。该图候选评分无节点穿越、标签遮挡或共线重叠；不据此承诺任意复杂图零交叉。
- 桌面方向切换、真实标签矩形、分步位置稳定、选择、缩放、历史恢复、流式预览及成品；保留既有窄屏回归，未增加窄屏实现。
- 请求实际参数：生成 low/high/max 后均为 low 复核；max 自动修复仍为 max；high 改造与修复仍为 high；追问不增加复核。
- 完整新文档、练习逐项覆盖、程序算例、共享修复预算、检查失败不保存、取消后重启。资料文字、网络摘要与原图仍进入复核，改造复核去除旧文档重复。
- 断线最多两次重试、静默超时不重跑、取消、日志与等待状态；波形和语言提示词示例满足契约，桌面观察、迁移题、练习记录与制卡保持正常。

实际查看自动分叉、Transformer 总览、横向切换和 low 复核进度截图，分别位于本地 `data/diagram-branch-auto-desktop.png`、`data/diagram-overview-desktop.png`、`data/diagram-branch-horizontal-desktop.png`、`data/content-review-desktop.png`。截图检查发现并修正方向切换时的旧高度适配问题，增加节点完整可见性断言。

修改的布局、生成、提示词、复核和进度组件通过定向 ESLint。首页只修改一条提示文案；完整首页 ESLint 仍有三处既有 `react-hooks/set-state-in-effect` 错误，已对上一提交原文复查，位置与数量相同；未改规则或掩盖这些存量问题。其余规则无新增错误。
