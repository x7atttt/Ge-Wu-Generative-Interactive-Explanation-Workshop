# 学习闭环打磨 · 自行验收指南

## 启动

在 `D:\Project\comp\app` 运行 `pnpm dev`，打开终端显示的本地地址。若之前已启动旧版本，请先停止再重启：这次新增了数据库表、字段和接口，旧进程不会自动完成全部迁移。

沿用 README 的环境配置，不需要安装新依赖。请新建一个专门的“迭代验收”空间，避免删除或修改自己的学习资料。

## 一、从新空间开始

1. 新建空间，看到“今天从这里开始”和“导入第一份资料”。点击后直接打开资料面板。
2. 准备一个 txt 文件，写入：

   ```text
   队列：先进先出，从队尾加入，从队头移除。
   栈：后进先出，从栈顶加入和移除。
   ```

3. 导入后，在资料条目点击“查看与纠错”。搜索“队列”，应显示匹配行。
4. 在“人工确认概念”中每行填一个：队列、栈，点击“保存概念”。关闭编辑器，再点“关闭资料”。地图应出现对应概念。

预期：无资料时能直接导入；有资料但无概念时，今日入口指引打开资料提炼概念。

## 二、学习状态与下一步

1. 点击概念生成讲解，完成其中的练习。少量作答后，概念应显示“待巩固”，不再直接算作路线完成。
2. 展开概念下的“学习依据”，查看讲解内练习次数、正确次数与卡片最近自评。
3. 当前规则是：讲解内练习至少 3 次且正确率不低于 60% 才显示“练习达标”；达到样本量但正确率不足则为“薄弱”。这是练习表现，不是掌握保证。
4. 生成学习路线后，对照“练习达标”计数与当前站。地图会在练习记录保存后刷新。

预期：客观练习与自评记忆分开展示；今日入口根据到期卡、薄弱概念、路线下一步提供可执行操作。

## 三、能恢复的综合自测

1. 打开“卡片”，手写添加几张题面不同的卡；概念填“队列”或“栈”。也可以从讲解底部“制成复习卡”。
2. 点“测验”→“开始新自测”，翻面后给第一题评“忘记”。
3. 点“保存并退出”，刷新整个页面，再进入同一空间的“测验”。应回到下一道未作答题，题序与已保存答案不变。
4. 完成剩余题。报告会自动保存；展开“本次作答明细”，应能回看每题题面、答案和本次自评。
5. 点击“复习本次忘记的卡”，只应包含本次忘记、仍存在且仍到期的卡片。已经处理的卡不会被重新拉入。
6. 关闭后再次进入“测验”，从报告列表打开刚才的报告，分概念结果仍在。有来源讲解的概念可点击“相关讲解”。

预期：分数明确来自自评。已保存的答案不会在恢复时重复改变复习排期；报告保留当时的题目与答案快照。

## 四、难卡可以暂缓

1. 点击“开始到期复习”，给一张卡评“忘记”，它应追加到本轮后面。
2. 对暂时记不住的卡点“稍后再练”，无需继续困在本轮；有来源讲解时可“查看原讲解”。
3. 暂缓本轮所有剩余卡，结束页应显示本轮卡片数、评分次数与暂缓张数。
4. 完成退出，再次打开复习。暂缓的卡仍应到期；“稍后再练”本身不会写评分或更改排期。

预期：本轮结束不会把暂缓说成“已清空到期任务”。最近自评忘记的概念会提示“建议回顾”，实际复习后按最新自评更新。

## 五、修正资料，保护历史依据

1. 打开先前生成的讲解，展开“生成时的资料依据”，确认记录了资料标题、版本及当时提供的正文上下文。
2. 在资料编辑器修改正文，点“保存正文并清空旧概念”。旧概念应被清空，需要重新提炼或人工确认。
3. 重新保存概念后，地图更新；已有路线应提示资料变更，需要重新生成。旧路线中已经移除的概念不能再触发无资料生成。
4. 回到旧讲解，资料依据仍应是修改前的快照。深化该讲解后仍继承该依据。
5. 更新前生成、没有存过快照的讲解，会明确提示“未记录”，不会用当前正文冒充历史依据。
6. 可用两个浏览器页签同时打开同一资料：甲保存后，乙再保存旧草稿应报告版本冲突。乙的草稿保留，先复制后重新加载。

预期：来源快照记录的是提供给模型的资料上下文，包含长度截断提示；它不表示每句话已完成事实核验。

## 六、失败恢复与窄屏

- 开发者工具中临时阻断地图接口，再完成或退出一次复习：原地图仍在，出现“重试加载地图”；解除阻断后重试可恢复。
- 路线编排失败时原路线仍在，可以“重试编排”；编排期间资料发生改变则拒绝保存旧结果。
- 编辑正文时临时断网，保存失败后草稿仍在；恢复网络后可以继续保存。
- 将浏览器缩窄，检查顶部空间选择、今日任务、资料编辑器与自测弹层；弹层内容可以滚动，键盘 Tab 留在弹层内，Escape 可退出。

## 自动验证

在没有运行中的开发服务器时先执行生产构建，然后运行验收脚本：

```shell
pnpm build
python test/run-learning-loop.py
node scripts/fsrs-verify.mjs
```

网页脚本需要本机已有 Python Playwright 与 Chromium。验收服务使用独立本地端口、本地模型替身及一次性空间，结束后删除测试实体并停止服务；不消耗真实模型、解析或搜索额度。截图与日志在 git 忽略的 `data/` 内。真实模型生成质量、PDF 解析质量仍需通过上面的手动流程核对。

完整 Lint 命令为 `pnpm lint`。仓库原有的 React Hooks 等问题仍单独记录在迭代规约实测结果中，不能把本轮接口/浏览器通过等同于全仓 Lint 已通过。
